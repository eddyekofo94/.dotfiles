# Prototype screenshots

These images are rendered from the actual ANSI frame captured from the
disposable tmux client running Herdr. They are evidence of the prototype state,
not design mockups. Final appearance in Ghostty still requires user review.

The `native-preview-clean`, `native-preview-cleared`, `native-preview-cycle-*`,
and `native-preview-focus-*` files are direct Ghostty screen captures from the
standalone-PNG lifecycle retry. The clean and cleared files show the successful
states; the cycle and focus files intentionally preserve stale-raster and
transient-black failure evidence.
