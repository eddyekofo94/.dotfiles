# Pi reload and verification-race diagnosis — 2026-07-30

## Trigger

Physical pass 3 could not reach interaction acceptance:

1. `/reload` crashed Pi because `stripPaintedCursor` was undefined.
2. Immediate relaunch failed FFF package verification twice.

## Root causes

### Reload crash

Pi re-evaluates `eddy-compat.ts` during `/reload` but can retain an older
imported ESM module. The running process had loaded `ui-core.mjs` before
`stripPaintedCursor`, slash parsing, and ranking exports existed. The new
entrypoint called an undefined cached export.

### Relaunch failure

The aggregate verifier called `pi/install.sh` twice against the default
physical-pilot state. That reinstalled the FFF npm tree in place. The launcher
correctly fails closed when it sees a partial or mismatched executable
dependency tree, but verification should never create that transient state for
a live user session.

One verifier had already sourced the default state path before the isolation
edit landed. It therefore continued touching live state until it exited; script
edits cannot alter variables already held by a running shell. This explains the
physical retry that failed after the source file itself looked fixed.

The live tree now has the exact reviewed file count and source/tree hashes.

## Fix and prevention

- The four new UI helpers live in `eddy-compat.ts`; only the pre-existing
  `extractPromptHistory` import remains.
- Static regression checks reject moving those helpers behind the cached ESM
  boundary.
- The real fixture executes production cursor/ranking assertions and exercises
  `/reload`.
- `pi/verify.sh` puts all mutable configuration, sessions, packages, and FFF
  databases under `pi/.runtime/verify/pilot-state`. It reuses only the pinned
  immutable binary.
- A simultaneous check proved that the live launcher and exact FFF tree remain
  available while aggregate verification runs.
- After all pre-fix verifier processes exited, a real interactive Fish PTY
  launched the live pilot, executed `/reload`, redrew the editor/footer, and
  exited cleanly.
- Aggregate Pi/Fish/ready-prompt verification passes. After fixing one
  isolation-test defect and one stale tracker statement, the fresh post-fix
  review reports Standards 0 findings and Fidelity 0 findings.

## Manual gate

physical pass 3 ended at the crash. Promotion remains blocked until Eddy can
rerun them.
