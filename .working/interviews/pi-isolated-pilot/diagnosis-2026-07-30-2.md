# Pi physical acceptance diagnosis — 2026-07-30, pass 2

## Trigger

The second physical Ghostty pass showed three acceptance failures after the
first cursor/Ctrl-L repair:

1. Ctrl-L could leave a blank viewport after `/reload`.
2. Pi's reverse-video painted cursor overlapped the hardware cursor.
3. `/re` selected `/resume` before the just-used `/reload`.

## Root causes

- Ctrl-L erased the terminal externally but requested an ordinary render. Pi's
  cached viewport could therefore be treated as unchanged. `requestRender(true)`
  is the supported full-invalidation path.
- `showHardwareCursor` exposes the terminal cursor at Pi's cursor marker; it
  does not remove Pi's painted cursor. The custom editor must remove only the
  reverse-video span immediately following that marker.
- Pi's combined slash autocomplete uses static fuzzy ordering. FFF owns file
  mentions, not slash-command ranking.
- Built-in commands such as `/reload` are consumed by Pi before extension
  `input` events. Usage must be observed at the custom editor's `onSubmit`
  boundary, where built-in and extension commands still share one path.

## Fix and prevention

- Ctrl-L now calls `tui.requestRender(true)`. The Herdr fixture checks the
  editor and footer immediately and again after a delayed render interval.
- The custom editor removes Pi's painted cursor while retaining its marker,
  requests a blinking vertical bar while focused, and restores a blinking
  block when focus leaves the prompt.
- Ghostty keeps a blinking block as its default and disables shell integration
  cursor rewriting; applications may still request their own DECSCUSR shape.
  Ghostty remains responsible for the unfocused outline.
- Slash usage is stored only under the isolated pilot control root. Matching
  suggestions put the most recent command first, then order remaining used
  commands by frequency and recency. Ranking is optional: unsafe/unavailable
  state fails open without blocking the real command. The append path rejects
  symlinks and multiply linked files and locks the file to mode `0600`.
- Pure regressions protect cursor stripping and ranking. The real
  Herdr-hosted Pi fixture submits `/reload`, proves its usage event, and
  verifies `/re` selects it first.
